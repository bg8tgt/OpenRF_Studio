# 合规与来源审核（干净室重建）

> 结论：本软件全部代码为本项目独立编写；未复制、未链接、未包含任何第三方源码或资源。
> 目标程序与第三方参考包已移出本仓库，逆向取证材料已删除。

## 1. 审核范围与方法

| 检查项 | 方法 | 结果 |
|---|---|---|
| 第三方代码/资源 | 扫描仓库内 DLL、密钥、CHM、厂商数据、参考包 | 已移出（见第 3 节） |
| 源码来源 | 逐模块核对注释、算法与依赖 | 仅公开公式与自写代码 |
| 反编译产物 | 检查是否存在反编译源码或对照数据 | 无（3.13 无反编译器，未产出源码） |
| 资源引用 | 检查工程是否引用外部路径/授权文件 | 无 |
| 许可 | 仓库 LICENSE | MIT（见 LICENSE 文件） |

## 2. 模块来源清单

| 模块 | 内容 | 来源 |
|---|---|---|
| app/engine.py、components.py | MNA 求解、R/L/C/TL/MS/COAX | Pozar 公开公式，自写 |
| app/components.py（S2P） | Touchstone 读取/插值 | Touchstone 1.0 公开标准，自写 |
| app/matching.py | 单枝节匹配 | 教科书闭式，自写 |
| app/rfmath.py | Γ/Z/Y、圆族、L 型匹配 | 教科书闭式，自写（v1.5 新内核） |
| app/smith.py | 圆图数学接口 | 基于 rfmath 的独立实现（v1.5 重写） |
| app/ui/plots.py、schematic.py | 绘图/原理图 | 自写 |
| app/ui/rf_workbench.py | 圆图工作台界面（v1.6 全新重写） | 自写 |
| app/ui/theme.py | 浅色/深色主题 | 自写 |
| app/ui/match_dialog.py | 匹配对话框 | 自写 |
| app/ai/* | AI 助手（协议/执行器） | 自写；OpenAI 兼容协议为公开格式 |
| app/balun.py、tline.py、inverse.py | 巴伦/传输线/反算 | 公开公式，自写 |
