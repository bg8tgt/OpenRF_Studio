## 审核一：数值交叉验证

用两套**独立实现**互相对照：AI 技能的 `circuit_build` 与 `synthesis + builders`。

- 低通 3/4 阶、高通 4 阶、带通、带阻的元件集合完全一致（同巴特沃斯原型）
- 两条装配路径的 S21 逐点一致（误差 < 1e-6 dB）
- 四种响应形状正确：低通通低阻高、高通反之、带通中心通、带阻中心阻
- 偶数阶（4 阶）高通/低通响应正确
- 带阻陷波位置随带宽移动（2–2.5 / 1–4 / 2.4–2.5 GHz 三组都落在 √(f1·f2)）

> 复核中发现一处**假警报**：高通偶数阶的元件顺序与技能实现相反。
> 逐点核对后确认是**镜像等价**（对称原型反转网络在端口互换下 S21 相同），
> 不是错误。审核脚本已改为按"元件集合 + 响应"比对。
