# 功能边界与路线图

> 目的：把"和专业射频设计套件比，现在能做什么、还差什么"讲清楚，并给出可执行的开发顺序。
> 状态：已实现 / 部分 / 未实现

## 1. 能力对照（按能力类别）

| 能力 | 专业套件通常具备 | 本软件 v1.2 | 说明 |
|---|---|---|---|
| 原理图编辑 | 图形化拖拽 + 层次化 | 部分：表格编辑 + 自动原理图 | 缺拖拽式连线编辑 |
| 线性 S 参数 | 有 | 已实现 | N 端口 MNA |
| 集总元件 | R/L/C 及更多 | 部分：理想 R/L/C | 缺互感、变压器、受控源 |
| 传输线 | 微带/带状/同轴/波导 | 部分：微带 + 带状线(计算) + 同轴(元件) | 缺波导与不连续性 |
| 微带综合 | 综合 + 不连续性 + 版图联动 | 部分：Z0↔线宽 + λ/4 | 无不连续性与版图 |
| 滤波器综合 | 多种响应/耦合矩阵 | 部分：低通/带通 LC 梯形 | 缺椭圆/贝塞尔/耦合矩阵 |
| 谐波平衡 | 有 | 未实现 | 非线性电路核心，需要引擎级投入 |
| 全波电磁 | 矩量法/有限元 | 未实现 | 需集成开源求解器，不宜自研 |
| 版图 / DRC | 有 | 未实现 | 不在本工具范围 |
| 器件模型库 | 厂商模型 | 未实现 | 需要协议与授权数据 |
| 优化 / 良率 | 有 | 未实现 | 可用目标函数 + 单纯形扩展 |
| 脚本接口 | COM/自动化 | 未实现 | 可直接调用本软件 Python 模块替代 |
| 数据交换 | Touchstone/CSV/ODB++ | 部分：Touchstone | 缺 ODB++/IPC-2581/GDS |
| 中文界面 | 少见 | 已实现 | 本软件的差异化 |
| 授权 | 商业授权 | MIT 免费 | 无授权限制 |

## 2. 版本 1.2 已验证能力

| 验证项 | 结果 |
|---|---|
| 串联 R、并联 C、理想线、λ/4 | 与解析解误差 <1e-12 |
| 3 阶切比雪夫低通 | 与闭式响应最大偏差 0.0005 dB |
| Wilkinson 三端口 | −3.01 dB、隔离 <1e-6 |
| 3 阶带通 2.3–2.7 GHz | 中心 −0.01 dB，抑制 −52/−43 dB |
| 同轴 50Ω 综合 | 回代 50.000000 Ω |
| 微带 / 带状线设计值 | 3.083 mm / 0.662 mm |
| L 型匹配 | |S11| < 1e-16（4 组阻抗 × 2 种拓扑） |
| 由 S11 反算 | Zin 精确，所需电抗精确 |
| Touchstone 往返 | ~1e-9 |
| 原理图 | 自动布局、并联支路接地、随电路重绘 |

## 3. 路线图

| 阶段 | 目标 | 工作量 | 价值 |
|---|---|---|---|
| v1.3 | 图形化原理图（拖拽元件、连线、旋转） | 2–3 周 | 易用性 |
| v1.3 | 微带不连续性（T 型结、阶跃、拐角） | 2 周 | 工程精度 |
| v1.8 | 优化器（Nelder–Mead + 目标/边界） | 已完成 | 设计闭环 |
| v1.4 | S2P 元件与器件模型导入 | 1 周 | 实测数据可用 |
| v1.5 | 分布式滤波器（耦合线、阶跃阻抗） | 2–3 周 | 微波滤波器 |
| v2.0 | 2.5D 矩量法（集成开源求解器） | 2–3 月 | 真正的电磁能力 |
| v2.1 | 谐波平衡（非线性稳态） | 2–3 月 | 功放/混频器 |
| 长期 | 版图 + 设计规则 + 器件库框架 | 6 月+ | 完整替代 |

## 4. 不建议的方向

* 不要通过修改/破解商业软件获得功能：法律风险 + 供应链风险；
* 不要复制商业器件库/模型库：属于厂商授权资产；
* 不要复制私有工程格式：本项目用自定义 JSON + 公开标准（Touchstone），避免侵权。
